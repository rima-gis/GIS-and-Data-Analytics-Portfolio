# Project 04 – Road Network of Nepal

**Description:**  
Designed a publication-quality road network map of Nepal using QGIS, demonstrating cartographic design, road classification, vector data visualization, and print layout creation.

---

## Tools Used

- QGIS 3.x

---

## Data Source

- OpenStreetMap
- geoBoundaries

---

## Skills Demonstrated

- GIS Cartography
- Road Classification
- Vector Data Visualization
- Symbology
- Print Layout Design
- Map Composition
