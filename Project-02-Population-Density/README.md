# Project 2: Population Density of Nepal by Province

## Overview
This project presents a population density map of the seven provinces of Nepal created using QGIS.

## Objectives
- Import and visualize provincial boundary data
- Join population data with spatial data
- Calculate and symbolize population density using graduated colors
- Label provinces
- Design a professional print layout
- Export publication-quality maps

## Software
- QGIS 3.x

## Data Source
- Hermes Download Center

## Skills Demonstrated
- GIS Data Management
- Attribute Table Join
- Choropleth Mapping
- Graduated Symbology
- Cartography
- Print Layout Design
- Map Export
