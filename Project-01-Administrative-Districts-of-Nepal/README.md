
# Project 1: Administrative Districts of Nepal

## Overview
This project presents a map of the administrative districts of Nepal created using QGIS.

## Objectives
- Import and visualize district boundary data
- Apply polygon symbology
- Label administrative districts
- Design a professional print layout
- Export publication-quality maps

## Software
- QGIS 3.x

## Data Source
- geoBoundaries (https://www.geoboundaries.org)

## Skills Demonstrated
- GIS Data Management
- Cartography
- Vector Data Visualization
- Print Layout Design
- Map Export
